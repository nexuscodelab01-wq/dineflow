# DineFlow

Restaurant ordering and management platform — full-stack SaaS-style demo project.

## Stack

- **Frontend:** Nuxt 4, Vue 3, TypeScript, Pinia, Tailwind CSS
- **Backend:** Python 3.12+, FastAPI, SQLAlchemy, Alembic
- **Database:** PostgreSQL
- **Infra:** Docker Compose

## Project structure

```
frontend/   Nuxt 4 application
backend/    FastAPI REST API
```

## Getting started

```bash
cp .env.example .env
docker compose up --build
```

Setup instructions and features will be added as development progresses.
